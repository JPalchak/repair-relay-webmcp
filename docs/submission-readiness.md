## External publication step

Devpost accepts only a public YouTube or Vimeo URL for the required video. The verified MP4 supplied with the handoff must be uploaded to one of those services, after which its public URL can be attached to the Devpost project and the final submission can be confirmed.

No application credentials are required for judges.
