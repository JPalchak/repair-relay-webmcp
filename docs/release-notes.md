# Release notes

## 1.0.0 — WebMCP Challenge release

- Added an evidence-first shared repair workbench.
- Added eight imperative WebMCP tools with closed schemas.
- Added deterministic compatibility, budget, evidence, and risk ranking.
- Added visible comparison and reversible plan staging.
- Added an explicit agent-to-human decision checkpoint.
- Added human-only plan approval and read-only approved-plan continuation.
- Added in-app recurring Luna review.
- Added scheduled repository Luna review with Actions summaries and preserved report artifacts.
- Added a 12-hour read-only conversational Luna review that returns prioritized improvements to the main thread.
- Added unit, contract, scenario, repository, and real-DOM browser tests.
- Added public deployment, Devpost copy, demo script, security model, and MIT license.
